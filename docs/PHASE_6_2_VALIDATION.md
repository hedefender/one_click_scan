Αποτελέσματα του συνθετικού συνόλου: `docs/IMAGE_SPIKE_RESULTS.md` (ενότητα «Phase 6.2»).

## 2. Τι άλλαξε για τον χρήστη

- **Flash** πάνω αριστερά στην κάμερα (κάτω από τη μπάρα): Off, Auto, On με πάτημα. Προεπιλογή Off. Τα Off και Auto θυμούνται. Το **On ισχύει μόνο για την τρέχουσα χρήση**: αν κλείσεις την εφαρμογή με On, ανοίγει σε **Auto**. Σε κινητό χωρίς flash το κουμπί δεν εμφανίζεται.
- **Tap-to-focus:** πάτημα στην προεπισκόπηση εστιάζει και μετρά έκθεση εκεί, με δαχτυλίδι που χάνεται μόνο του σε 1,5 s.
- **Χαμηλός φωτισμός:** ένδειξη «Χαμηλός φωτισμός» δίπλα στο flash όταν η προεπισκόπηση είναι σκοτεινή. Μετά τη λήψη ελέγχεται και η πραγματική φωτογραφία.
  - **One Click, Single Page:** σκοτεινή λήψη σταματά τη ροή με διάλογο: *Νέα λήψη* / *Συνέχεια ούτως ή άλλως* / *Συνέχεια με βελτίωση φωτισμού*. Η «Νέα λήψη» δεν αφήνει αρχεία πουθενά (η λήψη δεν είχε αποθηκευτεί ακόμα).
  - **One Click, Multi Page:** ο ρυθμός των λήψεων δεν σπάει. Μια μπάρα «Σκοτεινή λήψη: νέα λήψη;» (με κουμπί *Νέα λήψη* και κλείσιμο). Στο «Τέλος», αν έμεινε σελίδα σημαδεμένη χωρίς απόφαση, βγαίνει σύνοψη με τις τρεις επιλογές. Σκοτεινή σελίδα δεν στέλνεται ποτέ σιωπηλά.
  - **Με προεπισκόπηση:** καμία διακοπή. Στην οθόνη αποτελέσματος ένα banner «Βελτίωση φωτισμού» / «Όπως είναι».
- **Βελτίωση φωτισμού (αφαίρεση σκιάς, `flat`)** εφαρμόζεται **μόνο όταν την επιλέξεις**. **Δικλίδα:** διαβάζονται και οι δύο εκδοχές της σελίδας και κρατιέται αυτή με **περισσότερες λέξεις** (ισοπαλία: η αρχική). Το PDF δεν χάνει περιεχόμενο.
- Οι **φωτογραφίες** στον φάκελο και στο Gallery μένουν ακριβώς όπως τραβήχτηκαν, σε κάθε περίπτωση.
- **Κρυφή οθόνη διαγνωστικών φωτισμού:** Ρυθμίσεις, κάτω-κάτω, **5 γρήγορα πατήματα στο όνομα της εφαρμογής**.

Ο emulator **δεν** ελέγχει: πραγματικό flash, πραγματικό φως δωματίου, εστίαση πραγματικού φακού, ταχύτητα κινητού. Αυτά είναι στις ενότητες 4 έως 9.

### 3.1 Αναλυτής στην προεπισκόπηση (emulator x86, εικονική κάμερα)

Μέτρηση με την πραγματική κάμερα (plugin CameraX) σε προεπισκόπηση, 8 s χωρίς και 8 s με αναλυτή
(`integration_test/light_camera_test.dart`). Τα καρέ είναι build+raster, όπως στο spike του 6.0. **Ο emulator x86 με λογισμικό
γραφικών είναι αργός από μόνος του** (και χωρίς αναλυτή το 84% των καρέ περνά τα 33 ms), άρα τα νούμερα δείχνουν μόνο τη **διαφορά**, όχι την
ταχύτητα του κινητού.

| | Καρέ σε 8 s | Μέση τιμή | p95 | Μέγιστο | Καρέ πάνω από 33 ms |
|---|---|---|---|---|---|
| Αναλυτής **κλειστός** | 280 | 75,4 ms | 188,4 ms | 362,4 ms | 236 |
| Αναλυτής **ανοιχτός** | 204 | 88,0 ms | 203,8 ms | 536,0 ms | 185 |

- **Κόστος στον emulator:** +12,6 ms στη μέση τιμή, +15,4 ms στο p95, λιγότερα καρέ σε 8 s (204 αντί 280): ο αναλυτής **επιβαρύνει**
  την προεπισκόπηση εδώ. Δεν ξέρουμε πόσο θα επιβαρύνει στο κινητό. **Μέτρησέ το στη βαθμονόμηση (ενότητα 9)**: αν η προεπισκόπηση
  τρεμοπαίζει με την ένδειξη ενεργή, ο αναλυτής θα αραιώσει (`LightingConfig.analysisInterval`) ή θα κλείσει.
- **Ρυθμός δειγμάτων:** 13 δείγματα σε 16,5 s, δηλαδή **0,79 το δευτερόλεπτο**, όχι τα 2,5 του σχεδιασμού: ο κύκλος (άνοιγμα αναλυτή,
  αναμονή για ένα καρέ από την αργή εικονική κάμερα, spawn isolate, αναμονή 400 ms) κρατά περίπου 1,2 s στον emulator. Στο κινητό αναμένεται
  πιο γρήγορα, δεν μετρήθηκε.
- Μέτρηση της εικονικής σκηνής: χαρτί 84,7, αντίθεση 68,6 (άρα **δεν** θα προειδοποιούσε).
- Η λήψη όσο τρέχει ο αναλυτής δουλεύει και ο αναλυτής συνεχίζει μετά (ΝΑΙ). Το `focusAt` δεν πετά σφάλμα (ΝΑΙ). Ο emulator **δεν έχει flash**
  (`hasFlash: false`), άρα το κουμπί flash δεν εμφανίστηκε εκεί (σωστό).
- **Ο αναλυτής και το `flat` δεν τρέχουν στο UI isolate:** ο αναλυτής υπολογίζει με `Isolate.run` πάνω σε μεταφερόμενο buffer, το `flat` και η
  μέτρηση της λήψης τρέχουν σε δικό τους isolate (`IsolateLightEnhancer`, `compute`). Δεν υπάρχει αυτόματο τεστ που να το αποδεικνύει
  (μόνο ότι ο enhancer ολοκληρώνει, σταματά με cancel και timeout και δεν αφήνει αρχείο): η απόδειξη είναι ο κώδικας και η μέτρηση παραπάνω.

## 6. Βαθμονόμηση φωτισμού με τη διαγνωστική οθόνη

Άνοιξε τη διαγνωστική οθόνη (5 πατήματα στο όνομα της εφαρμογής, Ρυθμίσεις κάτω-κάτω). Στόχευσε ένα
λευκό χαρτί και σημείωσε τα **ζωντανά** νούμερα (άφησε 2 έως 3 s να σταθεροποιηθούν) και τα νούμερα της **δοκιμαστικής
λήψης** (κουμπί «Λήψη (μόνο μέτρηση)»). Το κατώφλι τώρα είναι **40** στο «επίπεδο χαρτιού». Το «flash required»
δείχνει `n/a` (δεν δίνεται από την κάμερα, βλ. ADR-030).

Κάθε γραμμή: χαρτί 0–100 και αντίθεση 0–100 (ζωντανά | λήψη). Στήλη «Θα προειδοποιούσε;» από την οθόνη.
Στήλη «Το κείμενο διαβάζεται στο PDF;» ναι/όχι από ένα πραγματικό σκανάρισμα στις ίδιες συνθήκες.

| Συνθήκη | Flash | Χαρτί ζωντανά | Αντίθεση ζωντανά | Χαρτί λήψη | Αντίθεση λήψη | Θα προειδοποιούσε; | Διαβάζεται στο PDF; |
|---|---|---|---|---|---|---|---|
| Φως ημέρας (δίπλα σε παράθυρο) | χωρίς | | | | | | |
| Φως ημέρας | με (On) | | | | | | |
| Εσωτερικός χώρος (κανονικό φως) | χωρίς | | | | | | |
| Εσωτερικός χώρος | με (On) | | | | | | |
| Σούρουπο / χαμηλό φως | χωρίς | | | | | | |
| Σούρουπο / χαμηλό φως | με (On) | | | | | | |
| Σκοτεινό δωμάτιο | χωρίς | | | | | | |
| Σκοτεινό δωμάτιο | με (On) | | | | | | |
| Θερμική απόδειξη, εσωτερικός χώρος | χωρίς | | | | | | |
| Μαύρο τραπέζι, λευκό χαρτί, εσωτερικός χώρος | χωρίς | | | | | | |

**Πώς θα οριστεί το κατώφλι:** το μεγαλύτερο «χαρτί λήψης» στο οποίο το κείμενο **δεν** διαβάζεται καλά στο PDF, και το
μικρότερο στο οποίο διαβάζεται, ορίζουν το εύρος. Το κατώφλι μπαίνει ανάμεσά τους (στο `lighting_config.dart`,
`minPaperLevel`). Σημείωσε αν η ένδειξη «Χαμηλός φωτισμός» της προεπισκόπησης συμφωνεί με το «θα προειδοποιούσε» της λήψης
(η σκηνή και το έγγραφο μπορεί να έχουν διαφορετικό φως).

## 10. Γνωστοί περιορισμοί

- Το σήμα «flash required» δεν δίνεται από το plugin της κάμερας (ADR-030). Η ένδειξη χαμηλού φωτισμού βασίζεται στη δική μας μέτρηση.
- Το κατώφλι 40 είναι αρχική τιμή· η σκηνή (προεπισκόπηση) μπορεί να έχει διαφορετικό φως από το έγγραφο.
- Μια θερμική απόδειξη με ξεθωριασμένο μελάνι έχει χαμηλότερο επίπεδο χαρτιού, άρα μπορεί να σημαδευτεί «σκοτεινή» νωρίτερα.
- Η εστίαση πριν τη λήψη: δεν προστέθηκε αναμονή (βλ. ADR-030, δεν μετρήθηκε στο κινητό).
- Άνοιγμα Multi Page με μίνι οδηγό λειτουργιών: στο «Polish phase» του ROADMAP.
