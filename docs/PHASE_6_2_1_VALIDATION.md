# Phase 6.2.1: έλεγχος στο κινητό (φακός με flash On, ένδειξη φωτισμού με φακό, δεύτερο όριο φωτισμού)

Απόφαση και λόγοι: ADR-031 (`docs/DECISIONS.md`). Αρχιτεκτονική: `docs/ARCHITECTURE.md` ενότητα 8j.
Προηγούμενος έλεγχος: `docs/PHASE_6_2_VALIDATION.md`.

## 1. Τι άλλαξε για τον χρήστη

- **Flash On = φακός (torch).** Ανάβει συνεχώς στην προεπισκόπηση, ώστε να φαίνεται το πραγματικό φως και να δουλεύουν σωστά η εστίαση και η έκθεση. Στη λήψη δεν υπάρχει δεύτερη λάμψη (το plugin βάζει το flash της λήψης σε Off όταν ο φακός είναι αναμμένος).
- **Auto και Off δεν άλλαξαν.** Ο φακός μένει σβηστός. Στο Auto το σύστημα ανάβει το flash μόνο στο κλείστρο, όταν χρειάζεται.
- **Το On αποθηκεύεται ως Auto** στην επανεκκίνηση. Η εφαρμογή δεν ανοίγει ποτέ με αναμμένο φακό.
- **Ο φακός σβήνει** όταν φεύγεις από την κάμερα, στο παρασκήνιο, στο κλείδωμα οθόνης και στις ειδοποιήσεις/διαλόγους συστήματος, στο «Τέλος» και στην αποστολή, σε διάλογο σκοτεινής λήψης, σε σφάλμα λήψης, σε επανασύνδεση κάμερας, και όταν αλλάζεις το flash σε Off ή Auto. Όταν γυρίσεις στην κάμερα και η επιλογή είναι ακόμα On, ξανανάβει.
- **Αυτόματο σβήσιμο:** μετά από 120 s χωρίς λήψη ή tap-to-focus ο φακός σβήνει, η επιλογή γίνεται Auto και βγαίνει μήνυμα: «Ο φακός σβήστηκε για να μη ζεσταίνεται το κινητό. Το φλας γύρισε σε αυτόματο.»
- **Κουμπί flash:** το On έχει εικονίδιο φακού. Ανάβει με κεχριμπαρί φόντο **μόνο όταν ο φακός καίει πραγματικά**.
- **Ένδειξη «Χαμηλός φωτισμός» με φακό:** μετά το άναμμα ή το σβήσιμο του φακού τα δείγματα αγνοούνται για 500 ms και η ένδειξη δεν αλλάζει μέχρι να συμφωνήσουν δύο νέα δείγματα.
- **Δεύτερο όριο φωτισμού (μόνο δομή).** Όταν το επίπεδο χαρτιού είναι κάτω από το `enhancementHelpsMinPaperLevel`, ο διάλογος, η σύνοψη και το banner λένε ότι η σελίδα είναι πολύ σκοτεινή και η βελτίωση πιθανότατα δεν θα διορθώσει το αποτέλεσμα. Η «Νέα λήψη» είναι η πρώτη επιλογή, οι άλλες μένουν.
  - **Προσοχή:** και τα δύο όρια είναι τώρα 40. Άρα **κάθε** σκοτεινή λήψη παίρνει τώρα το κείμενο «πολύ σκοτεινή». Το παλιό κείμενο θα ξαναφανεί μόνο όταν το όριο προειδοποίησης ανέβει πάνω από το δεύτερο.
- **Διαγνωστική οθόνη:** νέες γραμμές «Φακός» (αναμμένος/σβηστός), «Χρόνος από το τελευταίο άναμμα» και «Το τελευταίο live δείγμα πάρθηκε μετά το άναμμα» (ναι/όχι).
- **`flutter analyze`:** τα `spikes/**` αποκλείστηκαν στο `analysis_options.yaml`.

## 2. Τι εγκαθιστάς

- **APK:** δεν παραδόθηκε νέο APK σε αυτή τη φάση. Το χτίζεις με `flutter build apk --release` (ή `--debug`) όταν θέλεις να δοκιμάσεις. Η εγκατάσταση γίνεται από σένα. Ο `Test_Phone` και το κινητό σου δεν αγγίχτηκαν.
- Κανένα νέο πακέτο, άρα το `THIRD_PARTY_NOTICES.md` δεν αλλάζει.

## 3. Τι ελέγχθηκε στο PC και στον emulator (`Claude_Code_Test`)

## 4. Έλεγχος στο κινητό

### 4.1 Φακός

| Έλεγχος | Αναμενόμενο | Αποτέλεσμα |
|---|---|---|
| Flash On στην προεπισκόπηση | Ο φακός ανάβει και μένει αναμμένος, το κουμπί γίνεται κεχριμπαρί | |
| Σταθεροποίηση | Η εικόνα σταθεροποιείται σε περίπου μισό δευτερόλεπτο, χωρίς τρεμόπαιγμα | |
| **Ο φακός μένει αναμμένος με τον αναλυτή φωτισμού** (πρώτος έλεγχος, κρίσιμος) | Δεν σβήνει μόνος του ούτε τρεμοπαίζει ανά ~0,4 s | |
| Εστίαση στο σκοτάδι | Εστιάζει καλύτερα από το Auto | |
| Λήψη με On | Μία φωτογραφία, χωρίς δεύτερη λάμψη και χωρίς «flash πάνω στον φακό» | |
| Auto | Ο φακός μένει σβηστός, η λάμψη μόνο στο κλείστρο και μόνο όταν χρειάζεται | |
| Off | Τίποτα δεν ανάβει | |

| Έλεγχος | Αναμενόμενο | Αποτέλεσμα |

### 4.4 Βαθμονόμηση σούρουπου

Η μέτρηση γίνεται όποτε μπορεί ο χρήστης (απόγευμα). Σειρές: σταδιακά πιο χαμηλό φως, με και χωρίς φακό. Οι αριθμοί βγαίνουν από τη διαγνωστική οθόνη.

| Φως | Φακός | Χαρτί (ζωντανά) | Αντίθεση (ζωντανά) | Χαρτί (λήψη) | Αντίθεση (λήψη) | Θα προειδοποιούσε | Διαβάζεται στο PDF |
|---|---|---|---|---|---|---|---|
| | Off | | | | | | |
| | On | | | | | | |
| | Off | | | | | | |
| | On | | | | | | |
| | Off | | | | | | |
| | On | | | | | | |

**Προσοχή για το όριο 70.** Ο χρήστης πρότεινε όριο προειδοποίησης περίπου 70, ώστε η βελτίωση να προτείνεται στη ζώνη 40 έως 70 όπου βοηθά. Η απόδειξη θερμικού χαρτιού σε κανονικό εσωτερικό φως μετρήθηκε **79** (λήψη), και το ξεθωριασμένο μελάνι χαμηλώνει το επίπεδο. Με όριο 70 υπάρχει **κίνδυνος ψευδών προειδοποιήσεων** σε κανονικό φως. Η τιμή δεν αλλάζει τώρα: οι σταθερές `LightingConfig.minPaperLevel` και `enhancementHelpsMinPaperLevel` μένουν 40 και 40, και η απόφαση παίρνεται μετά τους παραπάνω πίνακες.
