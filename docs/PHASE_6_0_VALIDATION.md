# Phase 6.0: έλεγχος στο κινητό (spike εικόνας)

Αυτό το έγγραφο είναι για τον χειροκίνητο έλεγχο του spike. Η κύρια εφαρμογή δεν αλλάζει.
Τα αποτελέσματα των μετρήσεων στον emulator είναι στο `docs/IMAGE_SPIKE_RESULTS.md`.

## 1. Τι εγκαθιστάς

- **APK (release, arm64):** `C:\dev\one_click_scan\spikes\image_spike\build\image_spike_arm64_release.apk`
  (210 MB: περιέχει τα μοντέλα OCR και συνθετικές εικόνες δοκιμής. Είναι εργαλείο δοκιμής, όχι μέτρο μεγέθους).
- Πακέτο `com.example.image_spike`, ξεχωριστό από την κύρια εφαρμογή. Δεν αγγίζει τα δεδομένα της.
- Το APK **δεν στέλνει τίποτα πουθενά** και **δεν αποθηκεύει φωτογραφίες**. Μόνο αν πατήσεις «Αποθήκευση απαντήσεων» γράφει ένα
  αρχείο JSON με αριθμούς και ΝΑΙ/ΟΧΙ (όχι εικόνες, όχι κείμενο). Η φωτογραφία της κάμερας
  μένει όπου την αποθηκεύει η εφαρμογή κάμερας του κινητού (σβήσε τα δοκιμαστικά έγγραφα μετά).
- Η εγκατάσταση γίνεται από σένα (το δικό μου εργαλείο δεν αγγίζει το κινητό σου).

## 2. Οθόνες

- **Αρχική:** επιλογή μεθόδου (A3 Dart, A3 μικρά, A1 OpenCV), «Φωτογραφία με την κάμερα», «Επιλογή από τη συλλογή»,
  δοκιμή παρασκηνίου 5 και 21 σελίδων, και η λίστα των απαντήσεων.
- **Σύγκριση:** αριστερά το **πρωτότυπο** (ολόκληρο καρέ), δεξιά το **μετά** (κομμένο αν η ανίχνευση είναι σίγουρη,
  αλλιώς ολόκληρο το καρέ). Διακόπτης «αφαίρεση σκιάς», κουμπί «Μέτρηση OCR» (λέξεις και χρόνος, χωρίς κείμενο),
  και η ερώτηση **«Είναι η δεξιά εικόνα σωστή σελίδα για το PDF;» ΝΑΙ / ΟΧΙ**.
- **Παρασκήνιο:** τρέχει την ίδια δοκιμή με τον emulator, δύο φορές (σήμερα: μόνο OCR, νέο: κόψιμο και OCR) και δείχνει
  την αναμονή μετά την τελευταία λήψη και τα καρέ της οθόνης που άργησαν.

## 3. Πίνακας ελέγχου

Για κάθε γραμμή: φωτογράφισε ένα **δικό σου** έγγραφο (ή δοκιμαστικό), διάλεξε την κατάσταση στο πάνω μενού της οθόνης
σύγκρισης, κοίτα τη δεξιά εικόνα και πάτα ΝΑΙ ή ΟΧΙ. Σημείωσε στη στήλη «Παρατηρήσεις» ό,τι βλέπεις (π.χ. «έκοψε γράμματα στο κάτω μέρος»).
Ξεκίνα με τη μέθοδο **A3 (Dart)**· δοκίμασε και **A1 (OpenCV)** στα δύσκολα.

| # | Κατάσταση | Τι να κοιτάξεις | Μέθοδος | Κόπηκε; (ναι/όχι) | ΝΑΙ / ΟΧΙ | Παρατηρήσεις |
|---|---|---|---|---|---|---|
| 1 | Καλά φωτισμένο έγγραφο | Κόβει ακριβώς γύρω από τη σελίδα; Λείπει κάτι από τις άκρες; | A3 | | | |
| 2 | Κακοφωτισμένο (αμυδρό φως) | Βρίσκει τη σελίδα; Δες και τον διακόπτη σκιάς | A3 | | | |
| 3 | Τσαλακωμένη απόδειξη | Η σελίδα ισιώνει χωρίς να κόβεται κείμενο; | A3 | | | |
| 4 | Κεκλιμένο έγγραφο (γωνία) | Ίσιωσε και δεν στένεψε; | A3 | | | |
| 5 | Σκούρο φόντο | Βρίσκει τη σελίδα στο σκούρο; | A3 | | | |
| 6 | Έγγραφο εκτός καρέ (κομμένο στη φωτογραφία) | Πρέπει να πέσει σε ολόκληρο το καρέ, χωρίς να χαθεί τίποτα | A3 | | | |
| 7 | Μικρή απόδειξη σε μεγάλο τραπέζι | Με «A3»: μάλλον ολόκληρο το καρέ. Με «A3 μικρά»: κόβει την απόδειξη; | A3 και A3 μικρά | | | |
| 8 | Τραπέζι χωρίς έγγραφο ή με πολλά αντικείμενα | Δεν πρέπει να κόψει κάτι άσχετο (με «A3 μικρά» κοίτα προσεκτικά) | A3 μικρά | | | |
| 9 | Η πραγματική απόδειξη του Phase 2 (λαμπερό χαρτί, σκιά, πλάγια) | Μετράς OCR: λέξεις πριν και μετά | A3 και A1 | | | |

Αν μια σελίδα δεν κόπηκε και η εικόνα δεξιά είναι ολόκληρο το καρέ, πάτα ΝΑΙ μόνο αν είναι αποδεκτή ως σελίδα PDF.
Αν κόπηκε μέρος του κειμένου, πάτα ΟΧΙ και γράψε το στις παρατηρήσεις. Αυτό είναι το σοβαρότερο σφάλμα.

## 4. Μέτρηση OCR (προαιρετική)

Στις γραμμές 3, 7 και 9 πάτα «Μέτρηση OCR». Σημείωσε λέξεις και χρόνο πριν και μετά. Λιγότερες λέξεις στο «μετά» με
κομμένη σελίδα σημαίνει πιθανή απώλεια κειμένου.

## 5. Παρασκήνιο

Άνοιξε «Δοκιμή παρασκηνίου» για 5 και για 21 σελίδες, με «2,5 s» και με «όλες μαζί». Κοίτα τη μπάρα στην κορυφή: αν
κολλάει ή τρεμοπαίζει, σημείωσέ το. Στο τέλος σημείωσε:

| Σελίδες | Ρυθμός | Αναμονή μετά την τελευταία λήψη (σήμερα) | (νέο) | Καρέ πάνω από 33 ms (σήμερα / νέο) | Μπάρα κολλάει; |
|---|---|---|---|---|---|
| 5 | 2,5 s | | | | |
| 21 | 2,5 s | | | | |
| 21 | όλες μαζί | | | | |

Για σύγκριση, στον emulator: 21 σελίδες όλες μαζί 41,8 s (σήμερα) και 37,2 s (νέο). Με ρυθμό 2,5 s η αναμονή ήταν 2 έως 4 s και στα δύο.

## 6. Εστίαση (αναφορά, χωρίς αλλαγή της κάμερας)

Με την εφαρμογή κάμερας του κινητού: φωτογράφισε ένα κείμενο (α) αμέσως μόλις φέρεις το κινητό κοντά και (β) αφού περιμένεις ένα δευτερόλεπτο.
Σημείωσε αν το (α) βγαίνει πιο θολό. Έτσι ξέρουμε αν αξίζει μικρή αναμονή πριν το κλείστρο στη Phase 6.
(Η εφαρμογή σήμερα δεν περιμένει καμία ένδειξη εστίασης, βλ. ενότητα 7 του `IMAGE_SPIKE_RESULTS.md`.)

## 7. Τι μου στέλνεις πίσω

Τον πίνακα της ενότητας 3 και 5 συμπληρωμένο (ή τη λίστα από την αρχική οθόνη της εφαρμογής, που δείχνει ΝΑΙ/ΟΧΙ, κόψιμο και εμπιστοσύνη).
**Μη στείλεις φωτογραφίες εγγράφων** και μην γράψεις περιεχόμενό τους.

## 8. Τι δεν ελέγχθηκε από εμένα

- Η κάμερα και η συλλογή της εφαρμογής (system picker) δεν δοκιμάστηκαν στον emulator (θέλουν διαλόγους συστήματος). Η οθόνη σύγκρισης
  ελέγχθηκε με widget test και η αρχική οθόνη με στιγμιότυπο στον emulator.
- Ο ρυθμός καρέ δεν μετριέται σε headless τρέξιμο. Μετριέται μόνο στην οθόνη παρασκηνίου στο κινητό.
- Η εστιακή απόσταση διαβάζεται από το EXIF της φωτογραφίας. Αν λείπει, το ίσιωμα σελίδας με κλίση γίνεται με μέση τιμή απέναντι πλευρών (σελίδα ~6% πιο στενή στις 20°).
