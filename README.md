One-click document capture, local OCR, PDF and e-mail delivery. Privacy first,
fully local. Android first, iOS later.

## Setup (new clone)

This seed contains `lib/`, `test/`, `integration_test/`, `docs/`, and the
Android file that cannot be generated (`android_overlay/`). The platform
folders are generated by `flutter create`; see `docs/CLAUDE_CODE_PHASE_0.md`.

```
flutter pub get
flutter analyze
flutter test
```
