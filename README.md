# One Click Scan

One-click document capture, local OCR, PDF and e-mail delivery. Privacy first,
fully local. Android first, iOS later.

Output layout (from Phase 1): inside the folder you choose, `pictures/` holds
the original JPEGs and `pdf/` holds the PDFs, with matching names
(`YYYY-MM-DD_HH-MM-SS`). Scan produces no JSON; the Budget app reads the PDFs
directly. The app theme always follows the device theme.

Status: Phase 2 (OCR inside the app: Paddle PP-OCRv5 behind `OcrEngine`, upright working copy, language packs, OCR check screen; the OCR spikes of Phase 1.5 to 1.6c stay in `spikes/ocr_spike/` as the reference). See `docs/`:

## Setup (new clone)

This seed contains `lib/`, `test/`, `integration_test/`, `docs/`, and the
Android file that cannot be generated (`android_overlay/`). The platform
folders are generated by `flutter create`; see `docs/CLAUDE_CODE_PHASE_0.md`.

```
flutter pub get
tool/fetch_ocr_models.sh      # OCR models (about 28 MB, not in git), verified by SHA-256
flutter analyze
flutter test
```

Without the models the build and `flutter test` fail with a message that names
the missing file (`verifyOcrModels` in `android/app/build.gradle.kts`,
`test/services/ocr/ocr_assets_test.dart`).
